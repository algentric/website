# Analytics Setup

## Vercel Analytics
- **Visitor Tracking**: Automatically tracks page views and visitor sessions
- **Real-time Data**: Monitor website traffic as it happens  
- **Investor Insights**: See which sections investors spend time on
- **Geographic Data**: Track where your visitors are coming from

## Speed Insights
- **Performance Monitoring**: Track Core Web Vitals and loading times
- **User Experience**: Monitor how fast the site loads for visitors
- **Optimization**: Identify slow pages that need improvement

## Accessing Data
1. Deploy to Vercel
2. Visit your Vercel dashboard
3. Navigate to Analytics tab to see visitor data
4. Check Speed Insights for performance metrics

## Key Metrics to Monitor
- **Page Views**: Which sections get the most attention
- **Session Duration**: How long investors stay on the site
- **Bounce Rate**: Are visitors exploring multiple pages
- **Loading Speed**: Ensure fast performance for better impressions
